# Expansion Microscopy Demonstration Figures

## Getting Started
1. `cd` into envs directory.
2. execute the following command
   ```
   mamba create -f exm-demo-fig-py3.12-env.yml
   ```
3. Then activate the enviornment
   ```
   mamba activate exm-demo-fig-py3.12-env
   ```
4. `cd` do the source directory, then open  the analysis notebook
   ```
   jupyter lab analysis.ipynb
   ```
